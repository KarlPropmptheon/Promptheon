# Nils — Marketing Website

Marketing site for [Nils](https://nils.co) — the AI-powered business generator for Nordic and DACH solo operators.

## Stack

- **Next.js 15** (App Router, static export)
- **TypeScript**
- **Tailwind CSS 3**

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

Outputs a static site to `/out` via `next export`.

## Deploy

Connect this repository to Vercel. Static export is configured — no server runtime required.
